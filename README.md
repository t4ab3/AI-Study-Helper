# AI Helper

Chrome-расширение (Manifest V3) и локальный bridge на Python. Умеет две вещи:

- **Тесты.** Само проходит тест на странице: считывает вопрос, спрашивает веб-версию DeepSeek,
  выбирает ответ, нажимает «Далее» и так до последнего вопроса.
- **Конспект лекции.** Записывает звук лекции из вкладки или со всего компьютера и прямо во
  время записи переводит речь в текст. Потом DeepSeek делает из текста конспект, и он
  сохраняется в Word.

DeepSeek используется только через его сайт chat.deepseek.com в отдельном окне Chrome, без API и
токенов. Речь в текст переводит Whisper прямо на вашем компьютере (на видеокарте NVIDIA, если она
есть): звук никуда не отправляется.

Пошаговая инструкция от установки до работы, для обычного пользователя:
[docs/Инструкция AI Helper.docx](docs/Инструкция%20AI%20Helper.docx).

## Установка

1. **Bridge (Python 3.10+).** Запустите `bridge\start_bridge.bat`. При первом запуске скрипт
   создаст `.venv` и поставит Selenium, faster-whisper и python-docx. Если в компьютере есть
   видеокарта NVIDIA, он поставит ещё и её библиотеки CUDA. Всё вместе это около 1,5 ГБ, поэтому
   первый запуск займёт несколько минут. Bridge слушает только `127.0.0.1:8765`.
2. **Расширение.**
   ```
   cd extension
   npm install
   npm run build
   ```
   Затем откройте `chrome://extensions`, включите «Режим разработчика», нажмите
   «Загрузить распакованное» и выберите `extension\dist`. Если раньше было установлено
   AI Test Solver, нажмите у него «Обновить»: это то же расширение под новым именем.
3. Нажмите на иконку расширения, откроется боковая панель с вкладками «Тесты» и «Конспект».

Окно DeepSeek открывается с отдельным профилем `chrome-profile\deepseek`. Войдите в DeepSeek
вручную один раз: вход сохранится между запусками. Пароли и cookies никуда не копируются.

## Тесты

1. Запустите bridge и откройте тест на первом вопросе.
2. На вкладке «Тесты» нажмите **«Начать автоматическое решение»**.
3. Если вы ещё не вошли в DeepSeek, откроется окно DeepSeek и панель попросит войти. После
   входа решение продолжится само.

Дальше цикл идёт без вас: считываю вопрос → отправляю в DeepSeek → жду конца ответа →
проверяю JSON → заполняю → проверяю, что страница приняла ответ → «Далее» → жду новый вопрос.
Между этапами пауза 2,5 с (`TIMING.stepPauseMs` в `autoRunner.ts`), чтобы сайт и DeepSeek успевали.
Вопросы, которые сайт показывает по одному или открывает только после ответа, поддерживаются.

- **Если программа берёт не тот текст вопроса**, на первом вопросе выделите мышью текст вопроса,
  нажмите правую кнопку и выберите **«AI Helper: это текст вопроса»**. Программа запомнит для
  сайта, в каком элементе страницы лежит вопрос. С таким правилом вопросом считается только первая
  группа ответов под текстом вопроса, остальные группы переключателей на странице пропускаются.
- **Если кнопка «Далее» не нашлась**, нажмите на неё правой кнопкой и выберите **«AI Helper: это
  кнопка «Далее»»**. Или ничего не делайте заранее: после первого вопроса панель попросит нажать её
  один раз самому. Кнопки завершения теста не запоминаются. Кнопку, которая отправляет только
  один ответ и переходит дальше («Submit Answer», «Отправить ответ», «Submit and next»), запомнить
  можно; сама программа такую кнопку не ищет.
- **Если сайт не даёт открыть меню правой кнопкой**, используйте клавиши. Выделите текст вопроса и
  нажмите **K**. Наведите курсор на кнопку «Далее» и нажмите **M**. Клавиши меняются в панели, в
  блоке «Горячие клавиши» внизу вкладки «Тесты»; там же их можно выключить. Учитывается сама
  клавиша, а не буква, поэтому K работает и в русской или украинской раскладке («Л»). Клавиши
  срабатывают, даже если фокус остался в боковой панели: панель передаёт их странице. Если сайт
  перехватывает нажатия, клавиша ловится при отпускании. Пока курсор стоит в поле ввода, клавиши не
  срабатывают. Без выделения или без кнопки под курсором клавиша
  остаётся сайту: например, в YouTube K и M по-прежнему ставят на паузу и выключают звук.
- Запомненные правило и кнопка видны в панели, там же их можно «Забыть».
- **Приостановить / Продолжить / Остановить** работают в любой момент.
- Если ответ DeepSeek не подходит к вариантам, вопрос задаётся повторно (до 3 раз), потом решение
  останавливается. **Случайный вариант не выбирается.**
- Кнопку «Завершить тест / Отправить» программа только показывает. Нажимается она отдельной кнопкой
  в панели после подтверждения.
- CAPTCHA и вход в DeepSeek программа не обходит: она ждёт, пока вы пройдёте их сами.

## Конспект лекции

1. Запустите bridge, откройте вкладку «Конспект».
2. Выберите в выпадающем списке **язык лекции**: украинский, русский или английский. На этом
   языке распознаётся речь и пишется конспект. Выбор запоминается. При желании впишите название
   лекции и нажмите **«Начать запись»**. Chrome спросит, что записывать:
   - лекция в браузере (Meet, Zoom в браузере, YouTube, сайт вуза): вкладка с ней и
     **«Поделиться звуком вкладки»**;
   - программа Zoom, Teams, плеер: **«Весь экран»** и **«Поделиться системным звуком»**.
     Отдельное окно программы Chrome со звуком записывать не умеет, поэтому только так.
3. Во время записи в панели видно время, уровень звука и распознанный текст. Он появляется
   кусками примерно по 30 секунд.
4. **«Остановить запись»** (или «Закрыть доступ» в полосе Chrome). Остаток распознаётся за
   несколько секунд.
5. **«Сделать конспект».** Текст уходит в DeepSeek с просьбой составить подробный конспект для
   тетради: заголовки, термины с определениями, списки, формулы, выводы. Очень длинная лекция
   уходит частями. Готовый конспект откроется в Word сам. Потом его можно открыть кнопкой
   «Открыть конспект».

Вместо записи можно выбрать **готовый аудиофайл** (mp3, m4a, wav, ogg, видео mp4 и т. п.).

Всё лежит в папке `Конспекты\<дата> <название>\`: `Конспект — <название>.docx`, `текст лекции.txt`
(с отметками времени), `конспект.md` и сама запись `audio.wav`. Прошлые лекции есть в панели в
списке «Прошлые лекции», из него можно сделать конспект заново.

Пока идёт запись, не закрывайте боковую панель: звук записывается в ней. Если звук перестанет
приходить на 90 с (панель закрыли), bridge сам остановит запись и сохранит то, что успел
распознать.

### Распознавание речи

- Язык выбирается для каждой лекции в списке на вкладке «Конспект»: `uk`, `ru` или `en`. Он
  хранится в `meta.json` лекции, и конспект из прошлой лекции делается на её языке.
  `AIH_LANGUAGE` задаёт только язык по умолчанию в списке (если вы ещё ничего не выбирали).
- Модель: `large-v3-turbo` на видеокарте NVIDIA. В первый раз она скачивается (~1,6 ГБ) с
  Hugging Face, это видно в панели. Если видеокарты нет или её библиотеки не загрузились,
  используется модель `small` на процессоре: она медленнее и ошибается чаще. На процессоре
  распознавание может отставать от записи и догоняет после остановки.
- Другая модель: `AIH_WHISPER_MODEL` (например `medium`), устройство: `AIH_WHISPER_DEVICE=cpu`.
- В расшифровке бывают ошибки в словах. DeepSeek просят исправлять очевидные ошибки по смыслу и
  ничего не выдумывать. Проверяйте имена, числа и формулы по записи.

### Если DeepSeek изменил интерфейс

Bridge ищет поле ввода и ответы по селекторам из
[deepseek_chat.py](bridge/deepseek_bridge/deepseek_chat.py) (`DEFAULT_SELECTORS`). Проверить их:

```
cd bridge
.venv\Scripts\python -m deepseek_bridge --check
```

`--check-ask` ещё и отправляет в DeepSeek один короткий тестовый вопрос. Если что-то не найдено,
создайте `bridge\deepseek_selectors.json` с исправленными селекторами (ключи `input`,
`assistant_message`, `stop_button`, `send_button`…). Код менять не нужно.

## Поддерживаемые вопросы

Radio, checkbox, select, текстовые поля и textarea, true/false, сопоставление (таблица из
select с одинаковыми вариантами), кастомные `role=radio` / `role=checkbox`. Текст варианта
берётся и из соседнего блока, если переключатель лежит в своей обёртке (Testportal и подобные).
Если текстов вариантов нет (например, варианты — картинки), решение останавливается.

## Архитектура

```
extension/src/
  content/    recognize.ts (DOM → вопросы), questionRule.ts («это текст вопроса»), fill.ts,
              navigation.ts («Далее»), overlay.ts (подсветка, сообщения), index.ts (сообщения)
  sidepanel/  App.tsx (вкладки), AutoCard.tsx + autoRunner.ts (тесты),
              LectureCard.tsx + recorder.ts (запись звука), bridge.ts (клиент bridge)
  shared/     types, prompt.ts, answers.ts (разбор JSON), plan.ts, fingerprint.ts, logger.ts
bridge/deepseek_bridge/
  browser_manager.py  одно окно DeepSeek через Selenium, отдельный профиль
  deepseek_chat.py    ввод запроса, отправка, ожидание конца ответа, чтение текста и HTML ответа
  transcriber.py      Whisper (faster-whisper), видеокарта или процессор
  lecture.py          лекции: запись, живое распознавание, конспект через DeepSeek
  notes_docx.py       ответ DeepSeek (HTML) → Word
  server.py           HTTP API (только из chrome-extension://)
test-pages/           локальные тесты и lecture.html (http://127.0.0.1:8765/test-pages/)
```

## Тесты

```
cd extension && npm test                 # unit-тесты
cd bridge && .venv\Scripts\python -m pytest   # bridge, лекции на подставной модели
cd extension && npm run e2e:auto         # всё целиком: тесты и конспект (свой bridge на 8766)
```

`e2e:auto` гоняет настоящие расширение, bridge и Selenium-Chrome. Вместо DeepSeek там стоит
[fake-deepseek.html](test-pages/fake-deepseek.html), потому что тест не может войти в ваш аккаунт.
Блок конспекта записывает вкладку [lecture.html](test-pages/lecture.html) с русской записью
голосом Windows и распознаёт её настоящим Whisper, выбрав в списке русский язык. Пропустить этот блок можно
через `E2E_SKIP_LECTURE=1`.

## Ограничения

- Селекторы DeepSeek проверены на chat.deepseek.com в ноябре 2026. Кнопка Stop у DeepSeek без
  подписи, поэтому ответ считается законченным, когда текст перестаёт меняться: для тестов через
  5 с, для конспекта через 12 с.
- Новый ответ DeepSeek bridge узнаёт по метке: перед отправкой все ответы на странице помечаются,
  и новым считается ответ без метки после них.
- Порт bridge можно сменить: `AITS_PORT` для bridge и `bridgePort` в `chrome.storage.local`.
- Тесты внутри `<iframe>` не распознаются. Кастомные выпадающие списки (не `<select>`) не заполняются.
- Если bridge закрыли, а окно DeepSeek осталось открытым, следующий запуск bridge подключится к
  этому окну. Если Chrome с этим профилем открыт как-то иначе, закройте это окно и повторите.
