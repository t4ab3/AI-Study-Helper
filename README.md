# AI Helper

Расширение для Google Chrome с небольшой программой-помощником на Python. Работает через обычный сайт DeepSeek под вашим аккаунтом, без платных API и ключей.

## Что умеет

**Тесты**
- Само проходит тест на сайте: читает вопрос, спрашивает DeepSeek, отмечает ответ и нажимает «Далее».
- Понимает разные типы вопросов: один или несколько вариантов, выпадающие списки, текстовые поля, «верно/неверно», сопоставление.
- Если программа взяла не тот текст или не нашла кнопку, ей можно один раз подсказать правой кнопкой мыши.
- Наугад ответ не выбирается. Тест отправляется только после вашего подтверждения.

**Конспекты лекций**
- Записывает звук лекции из вкладки браузера (Meet, YouTube, сайт вуза) или со всего компьютера (Zoom, Teams).
- Прямо во время записи переводит речь в текст. Распознавание работает на вашем компьютере, звук никуда не отправляется.
- Лекция может быть на украинском, русском или английском: язык выбирается в списке.
- После лекции DeepSeek делает из текста подробный конспект, и он открывается в Word.
- Вместо записи можно загрузить готовый аудио- или видеофайл.

## Быстрый старт

Нужны Windows 10/11, Google Chrome, [Python 3.10+](https://www.python.org/) (при установке отметьте «Add python.exe to PATH») и [Node.js 18+](https://nodejs.org/).

1. Скачайте проект: **Code → Download ZIP** — и распакуйте его.
2. Соберите расширение. В папке `extension` выполните:
   ```
   npm install
   npm run build
   ```
3. Откройте `chrome://extensions`, включите **Режим разработчика**, нажмите **Загрузить распакованное расширение** и выберите папку `extension\dist`.
4. Запустите `bridge\start_bridge.bat`. Первый запуск занимает 5–15 минут: устанавливаются библиотеки. Окно не закрывайте.
5. Нажмите на значок AI Helper в Chrome, откроется боковая панель. При первом решении теста откроется окно DeepSeek: войдите в свой аккаунт один раз.

Для пробы есть учебные тесты: `http://127.0.0.1:8765/test-pages/` (адрес открывается, когда запущен bridge).
