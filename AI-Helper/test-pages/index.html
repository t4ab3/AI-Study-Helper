Тестовые страницы AI Helper

  • Single choice (radio, в том числе разметка как в Moodle)
  • Multiple choice (checkbox, fieldset)
  • Dropdown + matching (select, таблица сопоставления)
  • Text input (input, number, textarea)
  • True / False
  • Несколько типов вопросов + переход на следующую страницу
  • Звук лекции (для вкладки «Конспект»)
  • Кастомные элементы (role=radio / role=checkbox)

Страницы отдаются bridge-сервером: http://127.0.0.1:8765/test-pages/, либо откройте файлы напрямую (для file:// включите в расширении «Разрешить доступ к URL файлов»).
